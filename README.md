ExplainChess


ExplainChess is a Python-based chess project designed to analyze, simulate, and explain chess moves in a human-understandable way.

🚧 Project Status

⚠️ This project is still under development and not fully completed yet.
New features and improvements are continuously being added.

🎯 Project Goal

The main goal of this project is to:

Build a functional chess game
Integrate a chess engine (like Stockfish)
Provide clear explanations for moves, not just evaluations
Help beginners understand why a move is good or bad
🧠 Features
♟️ Full chess game simulation
🤖 Basic AI / engine integration
📊 Move evaluation system
💡 Move explanation (in progress)
🔊 Sound effects for moves
🛠️ Technologies Used
Python 🐍
Pygame (for UI)
Stockfish (Chess Engine)


⚠️ Notes
The project is still incomplete
Some features may not work properly yet
Code structure may change during development
